# Build Roadmap

This is the historical implementation roadmap. Use the codebase and root
README for current feature status; the sections below are not a release
verification checklist.

## Phase 1: Foundation

Goal:

- repository setup
- Docker
- PostgreSQL connection


## Phase 2: Database

Goal:

- Prisma schema
- migrations
- seed data


## Phase 3: Authentication

Goal:

- passenger login
- driver login
- JWT authorization


## Phase 4: Routing Foundation

Goal:

- integrate OSRM routing client
- store route snapshots
- calculate distance


## Phase 5: Ride Requests

Goal:

- create passenger requests
- calculate fares


## Phase 6: Pooling Engine

Goal:

- route compatibility
- pool matching
- capacity enforcement
- concurrency protection


## Phase 7: Driver Flow

Goal:

- accept rides
- lifecycle updates


## Phase 8: Frontend

Goal:

- passenger experience
- driver dashboard


## Phase 9: Release

Goal:

- tests
- documentation
- deployment
- demo video
